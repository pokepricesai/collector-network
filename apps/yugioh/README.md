# @collector-network/yugioh

Yu-Gi-Oh specialist site. Next.js 15 App Router.

Currently only a foundation — no product design, branding or data connections.

## Local development

```bash
pnpm --filter @collector-network/yugioh dev
```

Runs on <http://localhost:3001>.

## Deployment

Deployed as its **own** Vercel project with Root Directory set to `apps/yugioh`.
Has its **own** production domain — do not share deployments with the other
Collector Network sites.
