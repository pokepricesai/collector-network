## Activation + rollback procedures

### Activate images for one card (safest first step):
```sql
UPDATE pokemon_tcg_pilot_cohort SET images_enabled=true, activated_at=now()
WHERE pp_card_slug = '<slug>';
```
Then (in Vercel prod env): `PP_USE_TCGGRAPH_IMAGES=1`. Only that one card will see provider images.

### Activate prices for the same card:
```sql
UPDATE pokemon_tcg_pilot_cohort SET prices_enabled=true WHERE pp_card_slug='<slug>';
```
Then `PP_USE_TCGGRAPH_PRICES=1`.

### Rollback (any step):
```sql
UPDATE pokemon_tcg_pilot_cohort SET deactivated_at=now()
WHERE pp_card_slug='<slug>';
```
OR unset the env flag in Vercel.
